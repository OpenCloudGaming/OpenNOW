Two streamers, one seat.

OpenNOW’s native process speaks the same NVST two-socket shape as official GeForce NOW. Video still feels close. Mouse does not. The gap is not “we forgot Raw Input.” Qt already has that thread. Official tells the host accel=0, speed=10 on every focus change. No log or capture on this machine dumps those bytes.

Verdict

OpenNOW native · Qt

Owned RTSPS. Mjolnir video. Bundle audio and input. Media Foundation plus tearing present. Raw Input thread for relative mouse. Client-side type-7 tuning. No captured host mouse-settings frame. Native CloudMatch forces 8-bit 4:2:0. Audio has no jitter buffer and no RED. There is no microphone capture or send path.

Official GFN · this machine

Same sockets and NACK envelope. DX11 DXVA HEVC 10-bit at 2560×1440@120. WASAPI 16-bit with TimestampAudioBuffer and RED level 2. Raw Input async thread plus accel=0, speed=10 on every focus change. Session mouse accel disabled. SDLGamepad plus haptics feature 6.

The comparison is Qt native versus official Geronimo on this machine. Official GFN’s Chrome 128 shell is NVIDIA’s UI, not an OpenNOW path.

Decode and present

OpenNOW

MF hardware MFT, then the Microsoft D3D11-aware MFT. NV12 or P010 out. Swapchain BGRA, tearing, latency 1. Clock ignores RTP timestamps and learns cadence. Encoded queue cap 2. Overflow clears the reference chain.

Official

Dedicated DX11 DXVA device, 10 decode surfaces, FRL pacing. Present on a second device. Algemist continues. First frame 10-bit, chroma 3, limited range. UI vsync on, session vsync off.

Audio

Read the long form in audio.md.

Official concealment is a timestamped buffer plus RED. OpenNOW concealment is “drop the packet.” WASAPI underrun stops the client and raises preroll. That is a hole, not a fade.

ANNOUNCE still writes rtcMicOnNativeBundle:1 for compatibility, but the runtime has no microphone capture, encoder, queue or send path. Official mic this session was 20 ms, 2 ch, 16 kbps, RED 3.

OpenNOW collapses that to hidden versus visible. Type 0 and id 0 enter SDL relative mode and Raw Input type 7. Everything else is absolute type 5.

What official sends that we do not have as bytes

  1. Disabling session mouse acceleration at QUERY_GFN_START.
  2. Sending alt mouse settings (accel=0, speed=10) when the Raw Input async thread starts.
  3. Sending SDL mouse settings (accel=0, speed=10) on blur.
  4. NVB feature type 10 on those same moments. No hex in the logs.

OpenNOW’s capture-backed activation is enable-input, device descriptor 2, cursor capture on, track cursor on, window state 19, system state 0, enable-input. Then type 7 deltas, optionally scaled by OPENNOW_MOUSE_SENSITIVITY and OPENNOW_MOUSE_ACCELERATION.

Controller

Read the long form in controller-input.md.

The 38-byte type-12 packet and 15% radial deadzone are what OpenNOW sends. Native NVST then drops slot identity. gamepad_command() copies buttons, triggers, and sticks only. Inner index is hardcoded 0x03.

Official this session opened Xbox One through SDLGamepad, not a logged XInput poll. Haptics went out as feature type 6. OpenNOW has no rumble path on native or NVST.

Video recovery ladder

OpenNOW
  1. NACK gaps for 150 ms, 3 tries.
  2. Unrecoverable gap resets the assembler.
  3. RTCP PLI plus control 0x302 IDR.
  4. Drop inter-frames until a keyframe, then rebuild the MFT.
  5. Device loss recreates Graphics for 5 s, then class-preserving software fallback.
Official · 12:27 burst
  1. NACK. 639 of 677 used, 0 retries this session.
  2. Decode queue hits 30, then 40. Complete flush.
  3. IDR request for stream 0.
  4. Invalidation request after a dropped P-frame.
  5. Next I-frame. Stream[0]: recovered. Display may freeze on bad refs.

Official logged no PLI or FIR. OpenNOW has no invalidation command. Matching official recovery means adding that request, not sending more PLIs.
