# Desktop issue review for 1.0.4

Reviewed all 45 open issues and their discussions on 2026-11-08 against the Qt/native
`dev` branch. Source fixes, automated regressions, and reporter confirmation are
different kinds of evidence. A release containing a change does not establish
hardware or provider acceptance that has not been performed.

The desktop polish pass also addresses unstable Store shelves and Library filters,
Home rows overflowing smaller windows, redundant resize/layout work, crowded
settings rows and segmented controls, and non-contextual footer shortcuts. It
preserves the existing palette, artwork, navigation, and reduced-motion setting.
The Mac icon is authored in Apple's Icon Composer using the canonical OpenNOW
mark, with a native dark tile and a macOS-sized export for the bundle and Dock.
