OpenNOW SDK demo media provenance
================================

The fixture's RGB color patterns and 440 Hz stereo sine tone are generated by
OpenNOW example code. No commercial game footage, downloaded video, or account
data is included. The worker is based on the OpenNOW encoded-media fixture.
See the accompanying OpenNOW LICENSE.txt for the example code.

The reference worker builds OpenH264 from source rather than downloading a Cisco
binary. Codec patent and distribution obligations are separate from software
copyright licenses; this notice does not promise a patent license for arbitrary
redistribution. The worker's Cargo.lock records exact resolved dependencies.
